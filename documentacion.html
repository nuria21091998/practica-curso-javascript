Curso de JavaScript — Git y GitFlow

1. Introducción a Git

Git es un sistema de control de versiones que permite registrar los cambios de un proyecto, consultar su historial y trabajar con ramas para desarrollar funcionalidades de forma organizada.

Un repositorio almacena los archivos del proyecto y el historial de cambios. Un commit registra un conjunto de cambios con un mensaje descriptivo.

2. ¿Qué es GitFlow?

GitFlow es una estrategia de trabajo basada en ramas. Ayuda a separar el desarrollo de nuevas funcionalidades (develop), la preparación de versiones (releases) y las correcciones urgentes (hotfix).

  • main: contiene las versiones estables.
  • develop: reúne las funcionalidades en desarrollo.
  • feature/: permite trabajar en funcionalidades concretas.
  • release/: prepara una versión para su publicación.
  • hotfix/: permite corregir rápidamente una versión estable.
  • gh-pages: contiene la página de documentación publicada.

3. Funcionalidades desarrolladas

Modificar contenido HTML

La función cambiarContenido() utiliza document.getElementById() e innerHTML para cambiar el contenido de un párrafo.

Modificar atributos HTML

La función cambiarImagen() modifica el atributo src de una imagen para mostrar otra imagen.

Modificar estilos CSS

La función cambiarEstilos() modifica las propiedades style.color y style.fontSize de un elemento.

4. Proceso seguido con GitFlow

  1. Se creó el repositorio y la estructura inicial de la web.
  2. Se inició GitFlow con main como rama de producción y develop como rama de desarrollo.
  3. El Usuario 2 desarrolló las ramas feature/contenidoHTML y feature/atributosHTML.
  4. El Usuario 3 desarrolló feature/estilosCSS.
  5. Las funcionalidades se integraron en develop.
  6. Se preparó la versión v1.0 mediante una rama release.
  7. El Usuario 1 realizó una mejora mediante la rama hotfix/mejorasV_1_0.
  8. Se integró la corrección en main y develop y se subieron las ramas y etiquetas a GitHub.
